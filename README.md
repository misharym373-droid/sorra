# صُرة — SORRA

**كل ريال له مكان.**
تطبيق ويب عربي لإدارة أموالك: الدخل والمصاريف والميزانيات والأهداف، مع تسجيل تلقائي من رسائل البنك وApple Pay، ومزامنة بين أجهزتك.

## المزايا

- **العمليات:** مصاريف ودخل وتحويلات، تقسيم المصروف، تحويل بين حساباتك (ما ينحسب دخل ولا مصروف)، بحث وفلاتر وترتيب.
- **الرصيد الحقيقي:** «رصيدك المتاح الحين» يبدأ من رصيد بداية الدورة، و«المتاح اليوم» يتحسب من الفلوس اللي معك فعلًا.
- **الدورة المالية:** تبدأ من يوم راتبك، وكل الحسابات تمشي عليها.
- **الميزانيات:** شريط يتلون: أخضر، أصفر فوق 70٪، أحمر فاتح فوق 90٪، أحمر غامق لو تعدّيتها.
- **الأهداف والأقساط والاشتراكات:** تابي وتمارا وغيرها، مع الالتزامات القادمة.
- **التحليلات:** دونات، أعمدة، خط، تقويم حراري، قاعدة 50/30/20، وملخصات أسبوعية وشهرية.
- **التسجيل التلقائي:** من رسائل بنك الراجحي ومن Apple Pay عبر اختصارات iOS، بدون فتح التطبيق.
- **فلوسي AI:** محادثة عن فلوسك، وقراءة الفواتير بالكاميرا، والإدخال بالصوت.
- **الحساب والمزامنة:** تسجيل دخول، ومزامنة آمنة بين الجوال واللابتوب تدمج التغييرات بدل ما تكتب فوقها.
- **الملف الشخصي:** صورة شخصية أو أفاتار، الحسابات (الأساسي والادخار)، منتجاتي (مسار)، الإعدادات المالية، المظهر.
- **التصميم:** على أسلوب آبل: خط النظام، أسطح زجاجية، صفحات منبثقة تسحبها بإصبعك، ووضع داكن وفاتح، وتحترم «تقليل الحركة» و«تقليل الشفافية».
- **بياناتك:** تصدير CSV، تقرير HTML، استيراد كشف حساب، أرشيف مستندات، وسلة محذوفات مع تراجع.
- **يتثبت كتطبيق:** من سفاري ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

## الإعداد

### 1) Supabase
1. **SQL Editor** ← الصق `supabase/setup.sql` كامل ← **Run**. الملف آمن لو كررت تشغيله.
2. **Authentication ← URL Configuration**: حط رابط موقعك في **Site URL** (`https://misharym373-droid.github.io/sorra/`).
3. **Authentication ← Providers ← Email**: اختر تشغيل أو إطفاء **Confirm email**.
4. اختياري: لرسائل «نسيت كلمة المرور» لكل المستخدمين اربط SMTP خاص (مثل Resend) من **Authentication ← Emails ← SMTP Settings**.

رابط المشروع والمفتاح العام داخل `index.html` في السطر اللي يبدأ بـ `const SB=`.

### 2) فلوسي AI (اختياري، موصى به)
```bash
supabase login
supabase link --project-ref whhdabigebhoyhuqblid
supabase secrets set ANTHROPIC_API_KEY=ضع_مفتاحك_هنا
supabase functions deploy ai
```
الدالة تشتغل للمستخدم المسجّل دخول فقط. بدونها يشتغل فلوسي AI بتحليل محلي على الجهاز.

### 3) النشر على GitHub Pages
1. ارفع **كل محتويات** المجلد للمستودع، و`index.html` في الجذر.
2. **Settings ← Pages ← Deploy from a branch ← main / (root)**.
3. افتح `https://misharym373-droid.github.io/sorra/`. لو طلعت نسخة قديمة أضف `?v=` ورقم للرابط، مثل `?v=2`.

### 4) التسجيل التلقائي
داخل التطبيق: **الملف الشخصي ← حسابي ← زر Apple Pay**. التفاصيل الكاملة في [`docs/shortcuts.md`](docs/shortcuts.md).

## الأمان

- في `index.html` **المفتاح العام (publishable) فقط**، وهو مصمم يكون ظاهر. الحماية بـ Row Level Security.
- **لا ترفع** مفتاح `service_role` أو `sb_secret_` أو مفتاح Anthropic أو ملف `.env` لأي مكان.
- كل مستخدم يقرأ ويعدّل **صفّه فقط** (`auth.uid() = user_id`).
- رمز الاختصار (`p_token`) يقدر **يضيف** عمليات لصندوق الوارد فقط، ما يقرأ أي بيانات، وعليه حد 20 طلب بالدقيقة.
