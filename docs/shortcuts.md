# إعداد التسجيل التلقائي

صُرة تسجّل عملياتك تلقائيًا بطريقتين: من **رسائل بنك الراجحي**، ومن **Apple Pay**. الاثنين يشتغلون عبر **أتمتة في تطبيق الاختصارات** بالآيفون، بدون ما تفتح صُرة.

قبل ما تبدأ: افتح صُرة من رابط GitHub Pages وسجّل دخولك، ثم **الملف الشخصي ← حسابي ← زر Apple Pay**. بتلقى تبويبين (رسائل البنك / Apple Pay) وشرح متحرك و**3 قيم للنسخ**:

| القيمة | وين تحطها |
|---|---|
| الرابط | حقل الرابط في «إحضار محتويات الرابط» |
| المفتاح العام | رأس `apikey` |
| رمزك الخاص | حقل `p_token` |

## رسائل البنك (الراجحي)

1. الاختصارات ← **التحكم التلقائي** ← أتمتة جديدة ← **الرسالة**.
2. **المرسل:** `AlRajhiBank`.
3. اختر **تشغيل مباشرة** (عشان ما يسألك كل مرة).
4. أضف إجراء **إحضار محتويات الرابط**:
   - الرابط: `https://whhdabigebhoyhuqblid.supabase.co/rest/v1/rpc/ap_push_sms`
   - الطريقة: **POST**
   - الرؤوس: `apikey` = المفتاح العام، و`Content-Type` = `application/json`
   - نص الطلب **JSON** بحقلين: `p_token` = رمزك، و`p_text` = **مُدخل الاختصار** (محتوى الرسالة).

الرسائل المدعومة: شراء (PoS)، حوالة واردة وصادرة، راتب، **حوالة بين حساباتك**، استرداد، سحب. رموز التحقق تنتجاهل. الرسائل اللي ما انفهمت تطلع في «رسائل ما قدرت أقرأها».

## Apple Pay

1. الاختصارات ← **التحكم التلقائي** ← أتمتة جديدة ← **المحفظة**.
2. اختر بطاقتك، و**تشغيل مباشرة**.
3. إجراء **إحضار محتويات الرابط**:
   - الرابط: `https://whhdabigebhoyhuqblid.supabase.co/rest/v1/rpc/ap_push`
   - نفس الرأسين.
   - JSON: `p_token` = رمزك، و`p_amount` = المبلغ، و`p_merchant` = التاجر.

## نصايح

- **أضف آخر 4 أرقام** لكل حساب (الأساسي والادخار) في **الملف الشخصي ← الحسابات**، عشان التحويل بين حساباتك ينعرف وما ينحسب دخل أو مصروف.
- **أتمتة واحدة لكل حساب على جوال واحد.** لو نفس الحساب مربوط بجوالين، العمليات تتكرر.
- العمليات توصل لصندوق الوارد، وصُرة تسحبها أول ما تفتحها أو ترجع لها. وفيه زر «جلب العمليات الجديدة الآن».
- لو حسيت إن رمزك انكشف، اضغط **«رمز جديد»** وحدّث الاختصار.
