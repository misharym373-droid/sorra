# صُرة — تشغيل التطبيق خارج Claude مع الذكاء الاصطناعي

داخل Claude يشتغل فلوسي AI وقراءة الفواتير تلقائيًا. خارج Claude تحتاج هذا الخادم الصغير،
لأن مفتاح الذكاء الاصطناعي لازم يبقى في الخادم وما ينحط داخل التطبيق نفسه.

## التشغيل على جهازك (5 دقائق)
1. ثبّت Node.js نسخة 18 أو أحدث من nodejs.org
2. خذ مفتاح API من console.anthropic.com
3. داخل هذا المجلد: انسخ `.env.example` إلى ملف اسمه `.env` وضع مفتاحك في `ANTHROPIC_API_KEY`
4. شغّل: `node server.js`
5. افتح: http://localhost:3000

ما يحتاج أي `npm install`، الخادم بدون مكتبات خارجية.

## للجوال (آيفون وأندرويد)
المايك في المتصفح يحتاج رابط آمن (https). ارفع هذا المجلد على أي خدمة تشغّل Node.js وتعطيك https
(مثل Render أو Railway أو Fly.io)، وحط نفس متغيرات `.env` في إعدادات الخدمة.

مهم إذا رفعته على الإنترنت: ضع قيمة سرية في `APP_TOKEN`، واكتب نفس القيمة في التطبيق:
الملف الشخصي ← ربط الذكاء الاصطناعي ← رمز الوصول. بدونها أي أحد يعرف الرابط يقدر يستهلك مفتاحك.

## كيف يختار التطبيق طريقة الذكاء الاصطناعي
1. داخل Claude: يستخدم Claude مباشرة.
2. خارج Claude مع هذا الخادم: يستخدم خادمك (يكتشفه تلقائيًا لو فتحت التطبيق من رابط الخادم،
   أو تكتب الرابط في: الملف الشخصي ← ربط الذكاء الاصطناعي).
3. بدون أي اتصال: تحليل محلي على جهازك للأسئلة المالية، وفهم الجمل الصوتية محليًا،
   وقراءة الفواتير بقارئ نصوص يتحمّل على جهازك أول مرة (دقته أقل من الذكاء الاصطناعي).

## الخصوصية
- بياناتك محفوظة في متصفحك فقط.
- عند سؤال فلوسي AI يُرسل ملخص أرقامك وآخر عملياتك لتحليل السؤال فقط، وصورة الفاتورة عند قراءتها.
- ملف `.env` لا ترفعه لأي مستودع عام (موجود في `.gitignore`).

## الحسابات والمزامنة (Supabase)
التسجيل بالاسم ورقم الجوال والإيميل وكلمة المرور، والدخول بالإيميل. تشتغل من رابط GitHub أو خادمك (مو من داخل Claude).
1. في Supabase افتح SQL Editor، والصق محتوى `supabase-setup.sql` واضغط Run (مرة وحدة).
2. Authentication ← URL Configuration: حط رابط موقعك في Site URL (مثل https://اسمك.github.io/sorra/)
   عشان روابط تغيير كلمة المرور وتأكيد الإيميل ترجعك للموقع.
3. Authentication ← Sign In / Providers ← Email: خيار Confirm email
   - مطفي: التسجيل يدخلك فورًا (أسهل).
   - شغّال: لازم المستخدم يأكد إيميله أول.

مهم: خدمة الإيميل المجانية في Supabase ترسل فقط لإيميلات أعضاء فريق مشروعك، وبحد رسالتين بالساعة.
عشان توصل رسائل "نسيت كلمة المرور" وتأكيد الإيميل لأي مستخدم، اربط خدمة SMTP خاصة (مثل Resend)
من Authentication ← Emails ← SMTP Settings.

صور أرشيف المستندات تبقى على الجهاز ولا تتزامن.
